Project Documentation

This folder contains the documentation and visual results of the 32-bit RISC-V Single-Cycle Processor project.

Contents

1. Architecture Diagram – Block-level representation of the processor.
2. Elaborated Schematic – Vivado-generated RTL design schematic.
3. Simulation Waveform – Top-level processor simulation results.
4. Utilization Report – FPGA resource utilization after synthesis.

The "waveforms/" subfolder contains individual module simulation waveforms.
